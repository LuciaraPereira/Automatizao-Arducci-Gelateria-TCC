# Modelo de dados original do TCC

Figura recebida na conversa, já elaborada pela equipe. Entidades identificadas visualmente: Cliente, Comanda, Pedido, Solicitação_cancelamento, Pagamento, Perfil, Usuario_Interno, Item_Pedido, Item_Pedido_Opcao, Opcao, Grupo_Opcao, Produto_Grupo_Opcao, Produto, Categoria e Historico_Status_Pedido.

Não transcrevemos tipos, chaves ou cardinalidades da imagem como se fossem um esquema SQL validado. Para preservar o diagrama integral, colocar a exportação original em `figuras/modelo-dados-tcc.png` ou seu arquivo editável nesta pasta.

A figura não estava disponível como arquivo local para incorporação ao pacote. [Modelo complementar proposto](modelo-conceitual-proposto.md) trata os cenários novos separadamente.
